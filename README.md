# Lock In

menu bar focus timer. macOS 14+.

- timer or flow mode
- hides distracting apps while focused
- dims screens on break
- park stray thoughts for later
- pauses when you're away

`⌃⌥F` start/pause · `⌃⌥B` break · `⌃⌥P` park

```sh
scripts/build-app.sh --install   # no dev cert? LOCKIN_SIGN_IDENTITY=-
```
